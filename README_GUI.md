# 弹幕助手（GUI）

一个 Windows 桌面窗口，白色浅色界面，实时采集抖音直播间：

- **弹幕**：全部聊天，按「消费等级、粉丝团等级、昵称、弹幕内容」展示；
  - 消费等级 > 35 **或** 粉丝团灯牌 ≥ 15：浅金色底高亮；
  - 消费等级 > 40 **或** 粉丝团灯牌 ≥ 18：浅红底、深红字、加大加粗的超级高亮；
  - 普通弹幕保持白底，方便一眼筛选重点观众；
- **入场**：只显示粉丝团灯牌 **> 15 级** 的进入直播间消息；
- **礼物**：只显示整组累计总价值 **> 90 钻（9 元）** 的礼物，按「单价 × 本次数量」计算，连击按组内累计；每条显示为「送礼人 ID + 礼物名称 + × 数量 + 总钻石」；下方的「礼物总额 / 付费人数」统计**所有**礼物，不受 90 钻门槛影响；
- **本场直播总结**：当前在线、本场涨粉、付费人数、礼物总额、累计观看。

## 启动

```powershell
cd D:\DsProjects\DouyinLiveWebFetcher
.\.venv\Scripts\python.exe danmaku_gui.py
```

首次使用需要装依赖（已装过可跳过）：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

把直播间链接（如 `https://live.douyin.com/77217772750`）粘贴到顶部输入框，点「连接」。

默认窗口为 1600×1000，适合平板/大屏看弹幕；也可以拖动窗口边缘放大。

## 礼物必须填 Cookie

抖音现在只向**已登录账号**推送礼物消息；游客身份只能收到弹幕、进场、在线人数等，礼物分区会一直是空的。这是平台限制，不是程序漏抓。

获取方式：

1. 用 Chrome / Edge 打开 `https://live.douyin.com/`，确认已经登录；
2. 打开开发者工具：按 `Ctrl+Shift+I`，或右键页面 →「检查 / Inspect」，或浏览器菜单 →「更多工具」→「开发者工具」；
3. 点 `Network`（网络）→ 筛选 `Fetch/XHR` → 刷新页面；
4. 点一条发往 `live.douyin.com` 的请求 → `Headers` → `Request Headers` → 找到 `Cookie:`，复制整行值；
5. 把整行值粘贴到程序顶部的 **Cookie** 输入框，点 **保存**；或保存为项目目录下的 `cookie.txt`（程序启动时自动读取）。

`cookie.txt` 已加入 `.gitignore`，不会被提交。Cookie 等同于登录凭证，不要发给别人、不要截图外传；建议用一个只用于看直播的小号。

**不填 Cookie 也能用**：弹幕、入场、在线人数、涨粉、累计观看都正常，只有礼物相关统计为空。

## 输出文件

连接后自动在 `logs/` 下生成：

- `gui_<直播间>_<时间>.csv`：所有弹幕、>15 级入场、所有礼物（含未达到 90 钻展示门槛的）；
- `gifts_raw_<直播间>_<时间>.jsonl`：所有原始礼物消息，便于核对连击数量。

CSV 表头：

```text
received_at,kind,msg_id,user_id,nickname,fans_club_level,pay_level,content,gift_name,gift_count,diamonds,group_id,visible
```

## 导出按天网站

点顶部 **「导出网站」**，程序会读取 `logs/` 里所有 CSV/JSONL，生成：

```text
site/
  index.html              所有日期入口
  2026-11-17.html         每天一页（全部消息 + 当日礼物榜）
  assets/style.css
  manifest.json
```

- 每天一页，按采集时间升序；支持按「全部 / 弹幕 / 礼物 / 入场」筛选和关键词搜索。
- 当日礼物榜按 **用户 ID** 汇总当天全部礼物（包含 1 钻小礼物）；连击按整组合并。
- 纯静态页面，双击 `site/index.html` 即可看，不需要启动服务器。
- 命令行也可以单独生成：`python site_builder.py --logs logs --out site`
- 想先看样式：打开 `site_preview/index.html`（模拟数据）。

## 口径说明

- **涨粉**：从程序连接那一刻开始，用主播粉丝数的首次值做基线；连接前的涨粉不算。界面已标注「自连接时起算」。
- **付费人数**：本场发过礼物的去重发送人 ID；「其中粉丝团 N 人」是其中有粉丝团等级的人数。
- **在线人数**：优先用 `RoomUserSeqMessage.total`，没有时用 `RoomStatsMessage.display_value`。
- **礼物金额**：`gift.diamond_count` 是服务端下发的单价，10 钻 = 1 元；整组累计 >90 钻才进入礼物区，但「礼物总额」和「付费人数」统计所有礼物（含低价礼物）。
- **连击**：同一 `group_id` 的 `repeat_count` 是累计值，程序用「本次 − 上次」算增量，`repeat_end=1` 后清空该组。
- **弹幕历史**：只能抓连接之后的实时消息，拿不到连接前/开播以来的历史；抖音也可能限流/抽样，不能保证 100% 全量。

## 已知限制

- 抖音网页端会风控：长时间/多房间采集可能掉线、限流，程序每 5 秒自动重连；
- 语音直播间、部分活动礼物可能没有 `GiftMessage`；
- 同一礼物消息偶尔会收到两次，程序按 `msg_id` 去重；
- 本工具仅供个人看播/复盘，不要用于商业采集或传播他人信息。
