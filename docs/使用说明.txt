弹幕助手 · Windows 便携版（Aurora Dark）
================================

一、怎么启动
------------
1. 把整个 DouyinDanmaku 文件夹解压到任意位置（不要只把 exe 拖出来）。
2. 双击 DouyinDanmaku.exe。
3. 如果 Windows 弹出“未知发布者/SmartScreen”，点“更多信息” → “仍要运行”。

这个版本自带 Python 运行环境，其他电脑不需要安装 Python、Node 或依赖。
窗口是深色 Aurora 界面，适合平板/大屏观看；默认 1600×1000。

二、连接直播间
--------------
在右侧输入抖音直播间链接，例如：
    https://live.douyin.com/617650815017
然后点“连接”。

如果主播还没开播，状态会显示“等待开播…”，程序每 5 秒检测一次；
开播后会自动连接，不会把上次下播的在线人数当成实时数据。

三、礼物功能需要登录抖音
------------------------
抖音目前只向“已登录账号”推送礼物消息；游客身份只能收弹幕、进场和在线人数。
所以：
- 只看弹幕/在线人数：不登录也能用；
- 要看礼物、礼物总额、付费人数：必须先登录。

一键登录：
1. 点右侧状态区的“登录抖音”；
2. 会弹出一个独立的 Edge 窗口，用抖音 App 扫码或账号登录；
3. 登录成功后，程序会自动读取 Cookie 并保存到 cookie.txt，
   底部状态变成“已登录抖音：礼物消息可用”；
4. 关掉 Edge 登录窗口，回到主窗口点“连接”。

程序不接触密码，只读取登录后的 Cookie。登录配置保存在 login_profile/，
不会打进压缩包。Cookie 等于登录凭证，不要发给别人、不要上传网盘公开分享。

如果自动登录失败，也可以手动把 Cookie 保存为同目录下的 cookie.txt。

启动时会先检查 Cookie 状态：
- 未登录：直接弹窗提醒，底部红色显示“未登录抖音”；
- 已登录：底部绿色显示“已登录抖音 · Cookie 已加载”；
- Cookie 保存超过 7 天：弹窗提醒可能过期。

四、界面说明
------------
左右 75/25 双栏：左侧弹幕区占约 75%，右侧状态区占约 25%；底部是登录/采集状态。

1. 弹幕区（左侧）：
   - 列是「消费等级、粉丝团等级、昵称、弹幕内容」，正文 18px；
   - 长弹幕自动换行成两行，行高会随之增加；
   - 粉丝团灯牌 > 15 级的入场：青色高亮，内容为“入场 进入直播间”；
   - 消费等级 > 35 或粉丝团 >= 15：金色高亮；
   - 消费等级 > 40 或粉丝团 >= 18：红色最高级高亮；
   - 双击弹幕可复制完整内容。

2. 礼物区（右侧）：默认显示最近 5 条，可滚轮回看最多 50 条。
   - 只显示整组累计 > 90 钻（9 元）的礼物；
   - 每行格式：
     小番茄 送出了【跑车】×1 价值1,200钻
   - 不显示消费等级/粉丝团等级；昵称、礼物名、数量、金额加粗，整行 15px；
   - 连击会合并成整组数量，不会拆成很多条；
   - 超过 5 条时用鼠标滚轮或滚动条回看；
   - 礼物总额、付费人数统计所有礼物（包括 1 钻小礼物）。
   - 「星守护」「会员」「加入粉丝团」会单独识别为付费事件：
   - 加入粉丝团按 1 钻计入付费人数和礼物总额；
   - 星守护基础价 1280 钻、会员基础价 980 钻；消息文案里如果有「1980钻」「3个月」等信息，会优先按文案计算；
   - 文案没有价格/时长时才用基础价估算。

3. 右侧状态区：
   品牌/房间/连接按钮，当前在线 / 累计观看，2x2 指标：
   当前在线 / 本场涨粉 / 付费人数 / 礼物总额。

4. 界面不显示时间戳；导出的 CSV 和网站里保留完整时间戳。

   附带的“礼物样式预览.png”是用模拟数据展示礼物行格式，不是真实直播截图。

五、导出按天网站
----------------
点右侧状态区的「导出」按钮，会把 logs 里所有抓到的弹幕/礼物按日期生成静态网站，
输出到程序目录的 site_<直播间>/ 下，并自动用浏览器打开 index.html。
程序运行期间每 2 分钟会自动更新一次，关闭程序时再更新一次；
按直播日归档：从晚上开播、跨到第二天凌晨的直播，仍归在开播当天，不会拆成两页。
每天一页，支持筛选/搜索；网站最上面固定显示「抖音弹幕归档」；
首页「按日期查看」的日期卡片显示主播名、房间号；
日期页顶部也显示主播名/房间号；页面右侧是当日全天礼物榜（按用户 ID 汇总），
礼物榜顶部显示当日总额和付费人数，同一天多场直播会合并统计。
日期页还有「流速峰值 Top 10」：只统计弹幕，30 秒窗口，按独立发送人数排序，
峰值间隔至少 5 分钟；抽奖关键词直接过滤，重复文本默认排除并显示数量，可勾选查看。
日期页有「导出当日 CSV」「删除当日」，首页有「导出全部 CSV」，可直接下载。
「删除当日」只会在从程序里点「导出网站」打开的页面生效；直接双击 HTML 时
没有本地删除服务，会提示从程序打开。删除只影响归档网站，原始 logs 仍保留。

六、数据保存在哪
----------------
同目录 logs/ 下：
- gui_<直播间>_<时间>.csv：所有弹幕、入场、礼物（含低于 90 钻的）；
- gifts_raw_<直播间>_<时间>.jsonl：原始礼物消息，便于核对连击。

七、常见问题
------------
1. 礼物区一直空：
   先确认是否填了 Cookie；没有 Cookie 时抖音不推送礼物，这是平台限制。
2. 看不到 >15 级入场：
   测试房间可能没有这类观众；程序只显示粉丝团 > 15 级的入场。
3. 在线人数和 App 不一致：
   抖音 Web 端可能抽样，正常现象。
4. 换电脑：
   解压整个文件夹；礼物功能重新获取本机浏览器的 Cookie。
5. 杀毒软件误报：
   PyInstaller 单文件打包常见误报；可添加信任，或从源码运行。

八、限制
--------
- 只能采集连接之后的实时弹幕，拿不到连接前历史；
- 断线会自动重连，但重连期间的弹幕会丢失；
- 抖音可能限流/抽样，不能保证 100% 全量；
- 仅供个人复盘、研究使用，不要传播他人信息或商用。
