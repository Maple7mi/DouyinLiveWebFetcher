弹幕助手 · Windows 便携版
================================

一、怎么启动
------------
1. 把整个 DouyinDanmaku 文件夹解压到任意位置（不要只把 exe 拖出来）。
2. 双击 DouyinDanmaku.exe。
3. 如果 Windows 弹出“未知发布者/SmartScreen”，点“更多信息” → “仍要运行”。

这个版本自带 Python 运行环境，其他电脑不需要安装 Python、Node 或依赖。
窗口是白色浅色界面，适合平板/大屏观看；默认 1600×1000。

二、连接直播间
--------------
在顶部输入抖音直播间链接，例如：
    https://live.douyin.com/252464006047
然后点“连接”。

三、礼物功能需要登录 Cookie
--------------------------
抖音目前只向“已登录账号”推送礼物消息；游客身份只能收弹幕、进场和在线人数。
所以：
- 只看弹幕/在线人数：不填 Cookie 也能用；
- 要看礼物、礼物总额、付费人数：必须填 Cookie。

获取 Cookie（电脑浏览器）：
1. 用 Chrome/Edge 打开 https://live.douyin.com/ 并登录；
2. 按 Ctrl+Shift+I 打开开发者工具（没有 F12 也可以：右键页面 →“检查”）；
3. 点“网络 / Network”，刷新页面；
4. 点第一个 2524...?from_search=true 之类的请求；
5. 右侧“标头 / Headers” → “请求标头 / Request Headers”；
6. 找到 Cookie 一行，复制冒号后面的整段内容；
7. 回到弹幕助手，粘贴到顶部 Cookie 输入框，点“保存”。
   也可以把内容存成同目录下的 cookie.txt（程序启动会自动读取）。

注意：Cookie 等于登录凭证，不要发给别人、不要上传网盘公开分享。
换电脑建议重新登录获取，不要长期复用旧 Cookie。

四、四个分区
------------
1. 弹幕：全部聊天，按「消费等级、粉丝团等级、昵称、弹幕内容」展示；双击可复制完整内容。
   浅金色底：消费等级 > 35 或 粉丝团灯牌 >= 15；
   浅红色底/深红字/加大：消费等级 > 40 或 粉丝团灯牌 >= 18（超级高亮）；
   普通弹幕为白底，方便筛选重点观众。
2. 入场：只显示粉丝团灯牌 > 15 级的进场。
3. 礼物：只显示整组累计总价值 > 90 钻（9 元）的礼物；
   每条显示为「送礼人 ID + 礼物名称 × 数量 + 总钻石」；
   礼物总额、付费人数统计所有付费礼物（包括 1 钻的小礼物）。
4. 本场直播总结：当前在线、本场涨粉、付费人数、礼物总额、累计观看。

五、导出按天网站
----------------
点顶部「导出网站」，会把 logs 里所有抓到的弹幕/礼物按日期生成静态网站，
输出到程序目录的 site/ 下，并自动用浏览器打开 index.html。
每天一页，支持筛选/搜索；页面右侧是当日全天礼物榜（按用户 ID 汇总）。
（源码环境下也可以：python site_builder.py --logs logs --out site）

六、数据保存在哪
----------------
同目录 logs/ 下：
- gui_<房间号>_<时间>.csv：聊天/礼物明细，可用 Excel 打开；
- gifts_raw_<房间号>_<时间>.jsonl：原始礼物消息；
- 若开了调试，另有 debug.log。

七、已知限制
------------
- 只能抓“连接之后”的实时弹幕，拿不到连接前的历史；
- 抖音可能限流/抽样，不能保证 100% 全量；
- 断线会自动重连，但重连瞬间可能漏几条；
- 礼物消息依赖登录 Cookie，Cookie 失效后礼物区会变空；
- 本工具仅供个人学习/复盘，请勿传播他人隐私或商用。
